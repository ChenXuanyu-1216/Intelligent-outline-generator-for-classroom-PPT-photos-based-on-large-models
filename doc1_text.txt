五、启动方式

本章给出从零到服务可用的完整步骤，以及真实模型接入与常见问题处理。

（一）安装依赖

进入后端目录并安装依赖，建议使用虚拟环境隔离。

cd lecture-syllabus-generator/backend

python -m venv .venv

source .venv/bin/activate　　（Windows：.venv\Scripts\activate）

pip install -r requirements.txt

（二）启动服务

三种方式任选，效果等价。

方式一（推荐）：bash ../scripts/start_backend.sh　　（Windows 双击 scripts/start_backend.bat）

方式二：python run.py

方式三（热重载开发）：uvicorn app.main:app --reload --port 8000

服务监听 127.0.0.1:8000，可访问入口如下。

[table]
入口 | 地址 | 说明
前端上传页（ P1 ） | http://127.0.0.1:8000/ | 全流程起点
接口文档（ Swagger ） | http://127.0.0.1:8000/docs | 交互式契约，可逐项验证
健康检查 | http://127.0.0.1:8000/api/health | 返回服务状态与基线版本
基线自检 | http://127.0.0.1:8000/api/meta | 返回当前生效的阈值与配置

首次启动会自动完成两项初始化：在 backend/data/app.db 建立五张表结构；在 backend/storage/{task_id}/ 下建立任务目录。无需手工执行 SQL。

（三）接入真实多模态模型

复制环境变量样例并填写密钥即可切换为真实模型识别。

cd backend

cp .env.example .env

编辑 .env：APP_MODEL_PROVIDER=multimodal；APP_MODEL_API_KEY=你的密钥；APP_MODEL_NAME=模型名称

未配置密钥时默认走 mock 识别器，全链路依然可跑通，用于骨架联调与自动化测试；配置后即切换为真实模型识别，业务代码无需改动（由 Recognizer 接口隔离）。
