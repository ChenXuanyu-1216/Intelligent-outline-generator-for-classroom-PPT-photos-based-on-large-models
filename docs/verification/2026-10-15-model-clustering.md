## 实现范围

- 保留 `Clusterer.cluster(points, page_titles)` 接口及现有数据库结构。
- 新增 `APP_CLUSTER_PROVIDER=rule|model`，默认 `rule` 保持按来源页分组。模型模式独立于识别模式，复用 `APP_MODEL_*` 连接配置。
- 去重后的知识点分配本次请求专用的 `kp_1` 等临时 ID；模型只返回模块标题及 ID 数组。
- 校验每个 ID 恰好出现一次，拒绝未知、重复、遗漏、空模块、空标题、过长或多行标题、额外字段、错误类型、无效 JSON 和截断结果。
- 模型校验通过后从内存映射恢复原始知识点对象；正文、知识点类型、来源类型和全部来源页码不由模型重写。模块来源页码由程序求并集。
- 模型请求和 Markdown 渲染位于替换已保存知识点、大纲之前。聚类失败保留原有数据，返回统一错误，并将任务状态置为失败；不自动降级为规则结果。
- 超时、连接错误、HTTP 408、429、5xx 有限重试；其他 HTTP 错误、格式及 ID 校验失败不自动重试。服务商原始错误正文不进入对用户的错误消息。
