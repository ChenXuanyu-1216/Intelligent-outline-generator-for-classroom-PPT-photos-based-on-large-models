# 上传与任务创建可靠性验证

日期：2026-10-16。分支：`codex/reliable-upload-task-creation`。基线：`95f30f392585d014ccb03f4052b84147c84ca44d`。

## 交付范围

修复上传接口在全部超限时创建空任务、混合格式时遗漏有效文件、页数虚高、页码不连续，以及非法排序静默接受或变成服务器错误的问题。前端、识别、聚类与导出业务代码未修改，无新增第三方依赖。

`routers/tasks.py` 保持路由和成功响应结构，上传实现集中到 `services/upload_service.py`。

## 成功与失败契约

1. 先验证数量和完整排序，再按原始文件编号处理。排序必须是本批原始上传编号的完整排列；空值表示原始上传顺序。
2. 扩展名不支持、空文件和实际大小超限允许单文件拒绝。其余文件按用户顺序连续编号；有效页数、Page 行和落盘文件一一对应。全部被拒绝不创建 Task。
3. 同根独占暂存目录中按最多 64 KiB 读取，最多读取到上限加 1 字节判定超限；不信任声明大小。有效文件执行 flush/fsync，慢速文件接收期间不占用 SQLite 写事务。
4. 全部文件准备完毕后 flush 分配任务 ID、写入 Page，再将暂存目录发布到唯一任务目录，最后执行一次数据库 commit。成功响应在 commit 前构造，提交后不再 refresh。
5. 请求内普通异常回滚，并仅删除本请求创建、已验证绝对路径位于存储根目录下的目录。用户文件名仅保存为元数据，不用于磁盘目录名。
6. commit 抛错不代表未提交。先释放原会话，再用独立 Session 核对本任务的唯一文件路径：确认已提交则保留文件并返回成功；确认未提交才补偿清理；无法核对则保留目录并返回明确的不可盲目重试状态。

| 情况 | 结果 |
| --- | --- |
| 全部格式不支持或空内容 | 400 `FILE_FORMAT_ERROR` |
| 无有效文件且存在超限文件 | 400 `FILE_TOO_LARGE` |
| 数量超过配置 | 400 `TOO_MANY_FILES` |
| 排序缺失、重复、越界、非法字符、超长 | 400 `INVALID_FILE_ORDER` |
| 普通存储/数据库故障且已确认未提交 | 503 `UPLOAD_PERSISTENCE_ERROR`，可重试 |
| 发布后数据库状态无法核对 | 503 `UPLOAD_STATE_UNCERTAIN`，保留文件、先核查 |
| 操作系统拒绝清理 | 500 `UPLOAD_CLEANUP_ERROR`，明确提示维护者核对 |

`retryable=false` 是恢复建议，不是后续请求的去重机制；本轮未增加幂等键。

### 独立模型与故障矩阵

- 154 组固定生成输入：1–4 个文件、原始编号排列与扩展名拒绝组合，期望结果由输入模型独立计算，不调用生产排序或过滤函数。
- 字节边界：空文件、上限恰好命中、上限加 1、伪造声明大小、受限读取与完整内容一致性。
- 故障切点：输入读取、部分文件写入、暂存目录创建、fsync、Page flush、目录发布、commit、提交后的回调/确认、独立核对失败、清理被锁阻止。
- 并发：4 个线程处理 8 次成功上传，各批数据完整且目录互不覆盖；另一次测试让一个并发请求失败，其余批次与已有/旧格式目录内容保持不变。
- SQLAlchemy after_commit 使用真实数据库提交和真实事件触发；丢失提交确认也先执行真实 commit。未用伪数据库替代这些关键边界。

## 保证边界

- 数据库与文件系统没有共同事务；目录发布加异常补偿不是断电级分布式原子提交。强制终止可能遗留未引用目录，本轮不会启动自动删除扫描，以免清理其他请求或旧数据。
- 数据库不可用或文件被系统锁定时无法保证立即清理；本轮选择保留可诊断数据并显式报错，优先防止误删已提交内容。
- 大小控制作用于 multipart 解析后的业务读取，不等于网络接收阶段的请求体限流。内容检查仍是扩展名、非空、实际大小，不负责图片或 PDF 解码。
- 当前路由使用 Engine 绑定的 SessionLocal；不承诺任意外部调用者传入共享 Connection 的事务语义。
- 组合和变异检查是针对当前故障模型的验证，不是所有输入、硬件和崩溃情况的形式化证明。

## 设计依据

- [SQLite Atomic Commit](https://www.sqlite.org/atomiccommit.html)：数据库原子提交及其系统假设。

- [Python tempfile](https://docs.python.org/3.10/library/tempfile.html)：独占暂存目录创建。
